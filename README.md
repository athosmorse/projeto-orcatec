## Atalhos das Pastas Principais

Para facilitar a navegação pelo projeto sem precisar abrir pasta por pasta, utilize os atalhos abaixo para ir direto aos arquivos mais importantes:

* [🎨 Telas e Layouts (XML)](./app/src/main/res/layout) — Aqui ficam os arquivos visuais e o design das telas (como o Dashboard).
* [🧠 Lógica em Kotlin (Código-Fonte)](./app/src/androidTest/java/com/example/orcatec/ExampleInstrumentedTest.java) — Onde a mágica acontece (Activities, Adapters e regras de negócio).
* [📦 Configurações de Dependências](./gradle/libs.versions.toml) — Arquivo central de controle das versões das bibliotecas (como o RecyclerView).
